0. 创建”资产自动登记”应用
(1) 打开钉钉开放平台 -> 应用开发 -> 创建应用（企业内部应用）。
(2) 命名为：资产自动登记，保存应用。
(3) 配置“权限管理”：
    通讯录权限：employee.basicinfo (获取员工姓名、手机号等)。
    消息通知权限：robot 或 message 相关权限（发送工作通知）。
    通讯录部门成员读权限：qyapi_get_department_member (获取部门下的所有成员)。
    通讯录部门信息读权限：qyapi_get_department_list
(4) 获取应用凭证:
    在“凭证与基础信息”中获取

1.后台获取钉钉的公司通讯录中成员列表，
2.弹出窗口供用户选择自己姓名；
3.根据选择的姓名，发送钉钉验证码信息；
4.在窗口中输入验证码验证；
5.验证通过后，获取本机所有物理网卡的MAC地址；
6.遍历NAS上的Excel文件的内容，比较用户名下的MAC地址是否和当前获取到的所有MAC地址一致，如果一致，则弹出窗口提示“本机已完成登记，无须重复登记。”然后直接退出程序；
  如果没找到记录或记录不一致（更换、新增了网卡，或电脑更换了使用人），则删除该用户的所有原有记录，新增当前记录到表格中。
  表格信息：
    1.MAC地址
    2.有效日期：默认为0
    3.登记人  

7.添加成功后给admin发送一条信息。
